# ClearCut — AI Script Clearance Agent

Every script must be checked for names, brands, songs, and locations that could get a studio sued. It costs thousands and takes a week. ClearCut does it in minutes, with cited web evidence, using Gemini + Parallel Search.

Built for Agentic Cinema: The Blockbuster Hackathon (Google Cloud × Parallel track). Full README coming with the web UI and deploy steps.
